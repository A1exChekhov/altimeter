# Альтиметр · Errarium™ — Android и iPhone

В корне находится Android-приложение для Honor/Huawei. Нативная iPhone-версия
с Apple Health, Garmin-совместимостью, архивом GPX и WidgetKit находится в
[`ios/`](ios/README.md).

Красивый высотомер с картой, советами и интеграцией с часами Huawei.
Подпись: **Errarium™ by Aleksey Hermes** · [errarium.ai@gmail.com](mailto:errarium.ai@gmail.com).

- **Точная высота**: барометр + GPS. Барометрическая высота (гладкая, шум ~0,5 м)
  непрерывно «привязывается» к абсолютной высоте GPS медленным фильтром Калмана.
  Высота GPS берётся над уровнем моря (MSL): на Android 14+ из системы, иначе из
  NMEA-предложений GGA (поле MSL или поправка геоида) — без этого «сырой» GPS
  завышает/занижает высоту на 10–40 м (эллипсоид WGS84 ≠ уровень моря).
- **Туристическая карта MapLibre**: векторный онлайн-фон, тропы, пики, убежища,
  лагеря и вода; маркер, разворот на весь экран и цветная линия текущего либо
  выбранного GPX-трека. Региональные PMTiles v3 сохраняются локально, проверяются
  SHA-256 и работают без сети. Встроенный первый пакет — **Эверест** (Кхумбу,
  оба базовых лагеря и подходы) с отдельным офлайн-рельефом/hillshade и локальными
  подписями. Можно импортировать любой совместимый PMTiles с телефона или Google Drive.
- **Место**: название города/района (системный геокодер, при его отсутствии —
  Nominatim; работает на телефонах Huawei без Google-сервисов) + координаты.
- **Часы Huawei**: зеркалирование высоты без регистрации + чтение **пульса, SpO₂ и шагов**
  через локальный Health Connect.
- **Четыре виджета MagicOS/Android**: общий 4×1, «Высота» 2×1,
  «Здоровье» 2×1 и «Поход» 2×1.
  В «Высоте» крупно показана высота, ниже пульс и шаги; в «Здоровье» крупно
  показаны пульс, SpO₂ и шаги. Общий виджет также показывает трек. Обновляются
  при работе приложения и фоновой записи трека.
- **Советы и предупреждения**: горная болезнь (2500/3000/4000 м), быстрый набор
  высоты, низкий SpO₂, высокий пульс на высоте, тренд погоды по барометру
  (быстрое падение давления → возможная гроза), напоминание пить воду, слабый GPS.
- Общий цветной график высоты, пульса, SpO₂ и шагов с диапазонами 15 минут,
  1, 3 и 6 часов; мин/макс, суммарный подъём/спуск, вертикальная скорость,
  давление, единицы м/футы, тёмная «приборная» тема с цветом по высотной зоне.
- **Запись GPX-трека в фоне**: foreground-сервис пишет трек (координаты + точная
  высота фьюжн-фильтра + время) при выключенном экране; счётчики точек/дистанции/
  набора, автосохранение раз в минуту, кнопка «Поделиться» (GPX 1.1 — открывается
  в Locus, OsmAnd, Strava и т.д.). В карточке записи есть архив всех GPX и экспорт
  каждого файла, импорт с телефона/Google Drive и кнопка показа маршрута на карте. Файлы:
  `Android/data/com.chelmodeev.altimeter/files/tracks/`.
  Управление записью и архив вынесены с главного экрана в отдельную панель по
  кнопке маршрута в заголовке.
- **Заготовка приложения-приёмника для часов** — папка [`watch-app/`](watch-app/README.md):
  страница JS UI (высота, место, пульс, SpO₂, шаги), разбор P2P-сообщений, конфиг и
  пошаговая инструкция по сборке в DevEco Studio.

## Сборка

Проект — обычный Gradle/Android Studio проект (Kotlin, Jetpack Compose).

**Android Studio**: открыть папку `I:\Altimeter` → Sync → Run. Нужен только
Android SDK 34 (Studio предложит установить).

**Командная строка** (тулчейн уже лежит в `.toolchain`, скачан при создании проекта):

```bash
cd /i/Altimeter && JAVA_HOME=".toolchain/jdk17" GRADLE_USER_HOME=".toolchain/gradle-home" ".toolchain/gradle-8.13/bin/gradle" :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk` — скопируйте на
телефон и установите (разрешите установку из неизвестных источников).

Актуальная готовая сборка опубликована в GitHub Releases:
**[скачать Altimeter-v1.5.6.apk](https://github.com/A1exChekhov/altimeter/releases/download/v1.5.6/Altimeter-v1.5.6.apk)**.

Локальные готовые версии сохраняются раздельно в `I:\Altimeter\.release-artifacts\`
под именами `Altimeter-v1.3.apk`, `Altimeter-v1.4.apk`, `Altimeter-v1.5.apk`,
`Altimeter-v1.5.1.apk`, `Altimeter-v1.5.2.apk`, `Altimeter-v1.5.3.apk`,
`Altimeter-v1.5.4.apk`, `Altimeter-v1.5.5.apk`, `Altimeter-v1.5.6.apk` и т. д.; новая сборка не
перезаписывает предыдущую.

## Где находятся устанавливаемые файлы

### Android

На рабочем компьютере готовый debug APK находится здесь:

```text
I:\Altimeter\app\build\outputs\apk\debug\app-debug.apk
```

После самостоятельной сборки в любом клоне используется тот же относительный путь:
`app/build/outputs/apk/debug/app-debug.apk`. Каталог `app/build/` не хранится в дереве
Git, но готовый APK отдельно публикуется как asset релиза `v1.5.11`. Локально он создаётся
командой `:app:assembleDebug`.

Готовый Android 1.5.11: **[скачать APK](https://github.com/A1exChekhov/altimeter/releases/download/v1.5.11/Errarium-Altimeter-Android-1.5.11.apk)**.

### iPhone

Готовая подписанная IPA 1.2.0 опубликована отдельным релизом для зарегистрированного
iPhone: **[скачать IPA](https://github.com/A1exChekhov/altimeter/releases/download/ios-v1.2.0-ad-hoc/Errarium-Altimeter-iOS-1.2.0-AdHoc.ipa)**.
Установить её напрямую через Safari можно со страницы
**[a1exchekhov.github.io/altimeter/iphone/](https://a1exchekhov.github.io/altimeter/iphone/)**.
IPA подписана вашей Apple Developer Team и не является универсальной для незарегистрированных устройств.

После Build файл приложения обычно находится в:

```text
~/Library/Developer/Xcode/DerivedData/Altimeter-*/Build/Products/Debug-iphoneos/Altimeter.app
```

Архив для последующего экспорта создаётся через **Product → Archive** и сохраняется
в `~/Library/Developer/Xcode/Archives/`. При необходимости `.ipa` экспортируется из
Xcode Organizer с development/ad hoc подписью.

## Калибровка высоты (меню ⚙)

| Режим | Как работает | Когда использовать |
|---|---|---|
| **Авто (GPS)** | барометр привязывается к GPS сам | по умолчанию, всегда ок |
| **Вручную** | вводите известную высоту точки (табличка, отметка) | максимум точности здесь и сейчас |
| **QNH** | давление на уровне моря из METAR аэропорта | авиационный способ |

Оценка «±N м» — реальная сходимость фильтра: после пары минут под открытым
небом обычно ±2–4 м.

## Часы Huawei

### Канал 1 — работает сразу: зеркалирование уведомлений
Кнопка **«На часы»** (или автоотправка каждые 5 мин) публикует уведомление
`⛰ 1 248 м · место · координаты · давление (+ пульс/SpO₂/шаги)`. Huawei Health
показывает уведомления телефона на часах.

Включите: **Huawei Health → Устройства → ваши часы → Уведомления** → разрешить
для приложения «Альтиметр».

### Необязательный Wear Engine (для своего приложения на часах)
Кнопка **«Wear Engine»** шлёт JSON в приложение-приёмник на часах по P2P:

```json
{"type":"altimeter","ts":1755600000000,"altitude_m":1248.4,"accuracy_m":3.1,
 "pressure_hpa":871.2,"lat":43.65581,"lon":40.31226,"place":"Эсто-Садок",
 "vspeed_mpm":2.4,"hr_bpm":92,"spo2":96.0,"steps":8432,"ascent_m":523,"descent_m":118}
```

Что для этого нужно (один раз):
1. Аккаунт разработчика Huawei + проект в **AppGallery Connect**, включить API **Wear Engine** (заявка одобряется 1–2 дня).
2. Приложение-приёмник на часах (быстрое приложение HarmonyOS для Watch 3/4/GT со
   поддержкой быстрых приложений) — его **пакет** и **SHA-256 отпечаток подписи**
   пропишите в `gradle.properties` (`WATCH_APP_PACKAGE`, `WATCH_APP_FINGERPRINT`).
3. На телефоне установлен и авторизован **Huawei Health**.

В стандартной repo-сборке кнопка Wear Engine скрыта, потому что без Huawei App ID этот
канал всё равно не авторизуется. Пользуйтесь зеркалированием уведомлений; код P2P оставлен
в репозитории как необязательная интеграция на будущее.

## Пульс, SpO₂ и шаги

### Сборка из репозитория — без Huawei App ID

Это основной режим текущей сборки. Альтиметр читает пульс, SpO₂ и шаги из локальной базы
**Health Connect**. Сам Health Connect не забирает данные с часов: приложение-источник
должно сначала записать их туда. Для Huawei Watch 4 Pro в качестве такого источника
можно использовать Gadgetbridge: его актуальная версия умеет экспортировать шаги,
пульс и SpO₂.

Для Honor + Huawei Watch 4 Pro:

1. В Gadgetbridge откройте **Настройки → Внешние интеграции → Health Connect**.
2. В пункте **Устройства** обязательно выберите **HUAWEI WATCH 4**. Без выбора часов
   экспорт не запускается даже при выданных системных разрешениях.
3. В Health Connect откройте **Разрешения приложений → Gadgetbridge**, отзовите все
   старые разрешения, затем снова включите экспорт в Gadgetbridge. На новом системном
   запросе разрешите запись **Шагов**, **Пульса** и **Насыщения крови кислородом**.
4. Когда Gadgetbridge предложит начальную синхронизацию, выберите **Все доступные
   данные**. Включите **Синхронизировать после синхронизации устройства** и запустите
   обычную синхронизацию часов.
5. В Health Connect откройте **Данные и доступ** и убедитесь, что появились записи
   трёх типов. Разделы без записей Health Connect не показывает.
6. В Альтиметре нажмите **«Подключить Health Connect»** и разрешите чтение трёх типов.

Если после полного сброса разрешений передаются только шаги, обновите Gadgetbridge до
актуальной официальной сборки и повторите пункты 1–5. Источник каждой величины
показывается в карточке и на виджете.

### Необязательный прямой HUAWEI Health Kit

Перед выпуском APK требуется один раз настроить приложение разработчика:

1. Создать Android-приложение `com.chelmodeev.altimeter` в HUAWEI Developers/AppGallery Connect.
2. Добавить SHA-256 сертификата, которым подписан APK.
3. Подать заявку Health Kit на чтение **Heart rate**, **SpO₂** и **Steps** — это ограниченные
   медицинские разрешения, их одобряет Huawei.
4. Вписать числовой App ID в `HUAWEI_APP_ID` файла `gradle.properties`.
5. На телефоне установить актуальные HUAWEI Health и HMS Core, затем в карточке
   «Пульс, SpO₂ и шаги» нажать «Подключить HUAWEI Health».

Без совпадающих App ID, имени пакета, SHA-256 и одобренных scopes Huawei не выдаст
данные стороннему APK. Если `HUAWEI_APP_ID` пуст, эта интеграция автоматически скрыта,
а приложение работает только через Health Connect — никаких ошибок регистрации в UI.

### Пульс по Bluetooth без Huawei Developer

Для живого пульса HUAWEI App ID не требуется. На совместимых часах откройте
**Настройки → Трансляция данных ЧСС**, запустите трансляцию (при необходимости —
тренировку), затем в карточке здоровья нажмите **«Подключить пульс с часов»**.
Альтиметр подключится к стандартному Bluetooth Heart Rate Service. Этот канал
передаёт пульс только во время активной трансляции. SpO₂ через стандартную Bluetooth-
трансляцию Huawei не предоставляется; для истории SpO₂ нужен источник, записывающий
насыщение крови кислородом в Health Connect.

## Виджет

На Honor: удерживайте свободное место на главном экране → **Карточки/Виджеты** →
**Альтиметр**. Виджет показывает последний разрешённый снимок. Высота обновляется
при открытом приложении, путь — также во время фоновой GPX-записи, а пульс/SpO₂/шаги —
после чтения Health Connect в открытом приложении. Сам виджет не опрашивает здоровье
в фоне: он показывает последний разрешённый снимок.

## Офлайн-карты и локальные файлы

- **Настройки → Офлайн-карты регионов → Скачать** загружает карту Эвереста и
  рельеф в `Android/data/com.chelmodeev.altimeter/files/maps/`.
- Карты, контрольные суммы и GPX хранятся только на устройстве и не отправляются
  на сервер Errarium. Обновление APK их сохраняет; удаление приложения удалит.
- Кнопка **Импорт региона** использует системный выбор файла, поэтому видит локальное
  хранилище и Google Drive, привязанный к аккаунту Android.
- Архив треков позволяет импортировать GPX тем же способом; «Поделиться» экспортирует
  GPX в Google Drive, почту или любое выбранное пользователем приложение.
- На iPhone тот же принцип будет реализован через системные Files/iCloud Drive — без
  отдельного облачного аккаунта Errarium.

## Точность: что под капотом

- Барометрическая высота по стандартной атмосфере: `h = 44330·(1−(p/p₀)^0.1903)`.
- Поправка `MSL_GPS − h_baro` фильтруется скалярным Калманом: измерения
  взвешиваются вертикальной точностью фикса (`verticalAccuracyMeters`),
  дрейф погоды моделируется малым процессным шумом.
- MSL из GPS: Android 14 API → NMEA GGA (поле 9) → эллипсоид − геоид (поле 11) → сырой эллипсоид (помечается в чипе источника).
- Без барометра работает чистый GPS-фильтр (точность честно показывается хуже).
- Тренд погоды: давление приводится к уровню моря (иначе подъём выглядел бы как «падение давления») и оценивается за ~1–3 часа.

## Структура

```
app/src/main/java/com/chelmodeev/altimeter/
  MainActivity.kt, MainViewModel.kt      — вход и склейка
  core/      AltimeterCore — общий «двигатель» (датчики+фьюжн) для UI и сервиса
  sensors/   BarometerManager, LocationEngine (GPS + NMEA + спутники)
  logic/     FusionEngine (Калман), TrackStats, Advisor (советы)
  track/     TrackingService (foreground), GpxRecorder (GPX 1.1)
  health/    HealthReader (Health Connect) + необязательный HuaweiHealthReader
  widget/    домашний Android/MagicOS-виджет
  place/     PlaceResolver (геокодер + Nominatim)
  watch/     WatchNotifier (уведомления), WearEngineBridge (P2P)
  data/      SettingsRepository (DataStore)
  maps/      локальные PMTiles, каталог регионов, походный стиль и hillshade
  ui/        экран, карта MapLibre, график, настройки, тема
watch-app/   заготовка приложения-приёмника для часов (DevEco Studio)
```
