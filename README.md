# Альтиметр · Errarium™ — Android и iPhone

В корне находится Android-приложение для Honor/Huawei. Нативная iPhone-версия
с Apple Health, Garmin-совместимостью, архивом GPX и WidgetKit находится в
[`ios/`](ios/README.md).

Красивый высотомер с картой, советами и интеграцией с часами Huawei.
Подпись: **Errarium™ by Aleksey Hermes** · [errarium.ai@gmail.com](mailto:errarium.ai@gmail.com).

- **Точная высота**: барометр + GPS. Барометрическая высота (гладкая, шум ~0,5 м)
  непрерывно «привязывается» к абсолютной высоте GPS медленным фильтром Калмана.
  Высота GPS берётся над уровнем моря (MSL): на Android 14+ из системы, иначе из
  NMEA-предложений GGA (поле MSL или поправка геоида) — без этого «сырой» GPS
  завышает/занижает высоту на 10–40 м (эллипсоид WGS84 ≠ уровень моря).
- **Кусок карты** вокруг вас: OpenTopoMap (топографическая, с горизонталями)
  или обычная OSM; маркер, круг точности, разворот на весь экран. Без API-ключей.
- **Место**: название города/района (системный геокодер, при его отсутствии —
  Nominatim; работает на телефонах Huawei без Google-сервисов) + координаты.
- **Часы Huawei**: зеркалирование высоты без регистрации + чтение **пульса и SpO₂**
  через локальный Health Connect.
- **Виджет MagicOS/Android**: высота, дистанция и состояние GPX-записи, пульс и SpO₂
  с указанием источника. Обновляется при работе приложения и фоновой записи трека.
- **Советы и предупреждения**: горная болезнь (2500/3000/4000 м), быстрый набор
  высоты, низкий SpO₂, высокий пульс на высоте, тренд погоды по барометру
  (быстрое падение давления → возможная гроза), напоминание пить воду, слабый GPS.
- График высоты за час, мин/макс, суммарный подъём/спуск, вертикальная скорость,
  давление, единицы м/футы, тёмная «приборная» тема с цветом по высотной зоне.
- **Запись GPX-трека в фоне**: foreground-сервис пишет трек (координаты + точная
  высота фьюжн-фильтра + время) при выключенном экране; счётчики точек/дистанции/
  набора, автосохранение раз в минуту, кнопка «Поделиться» (GPX 1.1 — открывается
  в Locus, OsmAnd, Strava и т.д.). Файлы: `Android/data/com.chelmodeev.altimeter/files/tracks/`.
- **Заготовка приложения-приёмника для часов** — папка [`watch-app/`](watch-app/README.md):
  страница JS UI (высота, место, пульс, SpO₂), разбор P2P-сообщений, конфиг и
  пошаговая инструкция по сборке в DevEco Studio.

## Сборка

Проект — обычный Gradle/Android Studio проект (Kotlin, Jetpack Compose).

**Android Studio**: открыть папку `I:\Altimeter` → Sync → Run. Нужен только
Android SDK 34 (Studio предложит установить).

**Командная строка** (тулчейн уже лежит в `.toolchain`, скачан при создании проекта):

```bash
cd /i/Altimeter && JAVA_HOME=".toolchain/jdk17" GRADLE_USER_HOME=".toolchain/gradle-home" ".toolchain/gradle-8.13/bin/gradle" :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk` — скопируйте на
телефон и установите (разрешите установку из неизвестных источников).

## Калибровка высоты (меню ⚙)

| Режим | Как работает | Когда использовать |
|---|---|---|
| **Авто (GPS)** | барометр привязывается к GPS сам | по умолчанию, всегда ок |
| **Вручную** | вводите известную высоту точки (табличка, отметка) | максимум точности здесь и сейчас |
| **QNH** | давление на уровне моря из METAR аэропорта | авиационный способ |

Оценка «±N м» — реальная сходимость фильтра: после пары минут под открытым
небом обычно ±2–4 м.

## Часы Huawei

### Канал 1 — работает сразу: зеркалирование уведомлений
Кнопка **«На часы»** (или автоотправка каждые 5 мин) публикует уведомление
`⛰ 1 248 м · место · координаты · давление (+ пульс/SpO₂)`. Huawei Health
показывает уведомления телефона на часах.

Включите: **Huawei Health → Устройства → ваши часы → Уведомления** → разрешить
для приложения «Альтиметр».

### Необязательный Wear Engine (для своего приложения на часах)
Кнопка **«Wear Engine»** шлёт JSON в приложение-приёмник на часах по P2P:

```json
{"type":"altimeter","ts":1755600000000,"altitude_m":1248.4,"accuracy_m":3.1,
 "pressure_hpa":871.2,"lat":43.65581,"lon":40.31226,"place":"Эсто-Садок",
 "vspeed_mpm":2.4,"hr_bpm":92,"spo2":96.0,"ascent_m":523,"descent_m":118}
```

Что для этого нужно (один раз):
1. Аккаунт разработчика Huawei + проект в **AppGallery Connect**, включить API **Wear Engine** (заявка одобряется 1–2 дня).
2. Приложение-приёмник на часах (быстрое приложение HarmonyOS для Watch 3/4/GT со
   поддержкой быстрых приложений) — его **пакет** и **SHA-256 отпечаток подписи**
   пропишите в `gradle.properties` (`WATCH_APP_PACKAGE`, `WATCH_APP_FINGERPRINT`).
3. На телефоне установлен и авторизован **Huawei Health**.

В стандартной repo-сборке кнопка Wear Engine скрыта, потому что без Huawei App ID этот
канал всё равно не авторизуется. Пользуйтесь зеркалированием уведомлений; код P2P оставлен
в репозитории как необязательная интеграция на будущее.

## Пульс и SpO₂ с часов

### Сборка из репозитория — без Huawei App ID

Это основной режим текущей сборки. Альтиметр читает пульс и SpO₂ из локальной базы
**Health Connect**. Сам Health Connect не забирает данные из Huawei Health: другое
приложение должно сначала записать их туда.

Для Honor + Huawei Watch 4 Pro:

1. В Huawei Health откройте карточку часов → **Мониторинг здоровья** и включите
   «Непрерывный мониторинг пульса» и «Автоматическое измерение SpO₂».
2. Откройте Health Connect: на Android 14+ он находится в системных настройках
   конфиденциальности; на Android 9–13 устанавливается из Google Play.
3. Установите сторонний **Health Sync** (`nl.appyhapps.healthsync`), выберите
   источник **Huawei Health**, назначение **Health Connect** и включите типы
   **Heart rate** и **Oxygen saturation**. У приложения есть пробный период,
   затем требуется лицензия.
4. В Health Connect откройте **Данные и доступ** и убедитесь, что там появились
   записи пульса и кислорода.
5. В Альтиметре нажмите **«Подключить Health Connect»** и разрешите оба типа данных.

Если Huawei Health или другой уже установленный синхронизатор сам записывает оба типа
в Health Connect, пункт 3 не нужен. Источник каждой величины показывается в карточке
и на виджете.

### Необязательный прямой HUAWEI Health Kit

Перед выпуском APK требуется один раз настроить приложение разработчика:

1. Создать Android-приложение `com.chelmodeev.altimeter` в HUAWEI Developers/AppGallery Connect.
2. Добавить SHA-256 сертификата, которым подписан APK.
3. Подать заявку Health Kit на чтение **Heart rate** и **SpO₂** — это ограниченные
   медицинские разрешения, их одобряет Huawei.
4. Вписать числовой App ID в `HUAWEI_APP_ID` файла `gradle.properties`.
5. На телефоне установить актуальные HUAWEI Health и HMS Core, затем в карточке
   «Пульс и SpO₂» нажать «Подключить HUAWEI Health».

Без совпадающих App ID, имени пакета, SHA-256 и одобренных scopes Huawei не выдаст
данные стороннему APK. Если `HUAWEI_APP_ID` пуст, эта интеграция автоматически скрыта,
а приложение работает только через Health Connect — никаких ошибок регистрации в UI.

## Виджет

На Honor: удерживайте свободное место на главном экране → **Карточки/Виджеты** →
**Альтиметр**. Виджет показывает последний разрешённый снимок. Высота обновляется
при открытом приложении, путь — также во время фоновой GPX-записи, а пульс/SpO₂ —
после чтения Health Connect в открытом приложении. Сам виджет не опрашивает здоровье
в фоне: он показывает последний разрешённый снимок.

## Точность: что под капотом

- Барометрическая высота по стандартной атмосфере: `h = 44330·(1−(p/p₀)^0.1903)`.
- Поправка `MSL_GPS − h_baro` фильтруется скалярным Калманом: измерения
  взвешиваются вертикальной точностью фикса (`verticalAccuracyMeters`),
  дрейф погоды моделируется малым процессным шумом.
- MSL из GPS: Android 14 API → NMEA GGA (поле 9) → эллипсоид − геоид (поле 11) → сырой эллипсоид (помечается в чипе источника).
- Без барометра работает чистый GPS-фильтр (точность честно показывается хуже).
- Тренд погоды: давление приводится к уровню моря (иначе подъём выглядел бы как «падение давления») и оценивается за ~1–3 часа.

## Структура

```
app/src/main/java/com/chelmodeev/altimeter/
  MainActivity.kt, MainViewModel.kt      — вход и склейка
  core/      AltimeterCore — общий «двигатель» (датчики+фьюжн) для UI и сервиса
  sensors/   BarometerManager, LocationEngine (GPS + NMEA + спутники)
  logic/     FusionEngine (Калман), TrackStats, Advisor (советы)
  track/     TrackingService (foreground), GpxRecorder (GPX 1.1)
  health/    HealthReader (Health Connect) + необязательный HuaweiHealthReader
  widget/    домашний Android/MagicOS-виджет
  place/     PlaceResolver (геокодер + Nominatim)
  watch/     WatchNotifier (уведомления), WearEngineBridge (P2P)
  data/      SettingsRepository (DataStore)
  ui/        экран, карта (osmdroid), график, настройки, тема
watch-app/   заготовка приложения-приёмника для часов (DevEco Studio)
```
